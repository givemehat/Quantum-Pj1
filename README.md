Welcome to Quantum-Pj1! This repository contains a collection of Quantum Computing experiments and algorithmic simulations.

## Overview
This project explores the fascinating world of quantum mechanics applied to computation. It serves as an experimental sandbox for building, testing, and simulating quantum circuits.

## Goals
- Simulate quantum logic gates and operations.
- Benchmark quantum algorithms against classical counterparts.
- Provide a clear, readable codebase for quantum research.
